# Changelog

Все значимые изменения в проекте документируются в этом файле согласно стандарту [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-10-19

### Added
- Полный переход на формат экспорта JSON (`steam_curators_{user}_{date}.json`) вместо устаревшего Excel XML.
- Локальная база данных (`GM_setValue` / `localStorage`) для сохранения профиля текущего пользователя с именем, количеством кураторов и меткой времени обновления.
- Интерактивный компаратор баз кураторов:
  - Сравнение локальной базы с загруженной внешней базой JSON.
  - Отображение имен обоих пользователей, количества кураторов и дат снимков.
  - Фильтр-переключатель «Показать только отличающиеся».
  - Раздельные цветовые бейджи для статусов: 🟢 Общие, 🔵 Только у вас, 🟠 Только у собеседника.
  - Кликабельные ссылки с переходом на страницу каждого куратора.
  - Живой поиск по названию куратора.
- Кроссплатформенная поддержка Chrome и Firefox в Tampermonkey и Violentmonkey.
- Модульный тест `test_comparator.js` для верификации алгоритма сравнения.
- Автоматизированный скрипт сборки и упаковки `build.ps1`.

### Removed
- Устаревший экспорт в псевдо-Excel (HTML-таблица в формате XLS).
