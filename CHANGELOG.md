# Changelog

Все значимые изменения в проекте документируются в этом файле согласно стандарту [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и [Semantic Versioning](https://semver.org/lang/ru/).

## [2.1.0] - 2026-10-19

### Added
- Автоопределение нового пользователя: при отсутствии локальной базы выводится информационный баннер с кнопкой перехода к кураторам.
- Поддержка страницы `/curators/mycurators` в `steam-curator-tracker.user.js`:
  - Функция первичного обхода кураторки с автоскроллом и сбором всех текущих подписок.
  - Фиксация даты создания базы данных (`createdAt`).
  - Всем кураторам из первичного обхода присваивается дата создания базы данных как дата подписки (`followedAt = createdAt`).
- Усовершенствована логика сортировки при экспорте:
  - Активные подписки гарантированно идут первыми (от самых недавних ручных подписок к кураторам из начального пула создания БД);
  - Отписанные кураторы идут в конце списка, отсортированные по дате отписки.
- Расширены модульные тесты в `test_tracker.js` (проверка полного сценария заведения базы, первичного обхода и приоритетной сортировки).

## [2.0.0] - 2026-10-19

### Added
- Создан новый юзерскрипт `steam-curator-tracker.user.js` для страниц кураторов Steam (`/curator/*`):
  - Реактивное отслеживание действий подписки и отписки на кураторов в реальном времени.
  - Ведение персистентной локальной базы кураторов с фиксацией `steam_id`, имени пользователя, даты подписки (`followedAt`) и даты отписки (`unfollowedAt`).
  - Отображение статусного виджета в шапке страницы куратора:
    - 🟢 *Подписан: [Дата]* или *Подписан: Дата неизвестна (до начала ведения базы)*.
    - 🔴 *Отписан: [Дата]* или ⚪ *Новый куратор (ранее не отслеживался)*.
  - Кнопка скачивания базы в формате JSON, отсортированной по дате подписки.
- Автоматические модульные тесты `test_tracker.js`.
- Сценарий автоматической сборки `build.ps1`.

### Changed
- Предыдущий скрипт пакетного сбора и сравнения `steam-curators-sync.user.js` переведен в архивный статус (v1.0.0).

## [1.0.0] - 2026-10-19

### Added
- Переход на формат экспорта JSON вместо устаревшего Excel XML.
- Локальная база данных одного текущего пользователя для страницы `/curators/mycurators`.
- Компаратор баз кураторов с фильтром по различиям и быстрыми ссылками на профили.
- Модульный тест `test_comparator.js`.
