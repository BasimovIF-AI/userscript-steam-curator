# Changelog

Все значимые изменения в проекте документируются в этом файле согласно стандарту [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и [Semantic Versioning](https://semver.org/lang/ru/).

## [2.3.0] - 2026-10-19

### Added
- Интерактивное модальное окно ревизии и быстрой отписки от кураторов (`renderCuratorsViewerModal`):
  - Сортировка по дате подписки: режим «⏳ Сначала старые (для отписки)» и «⏱️ Сначала новые».
  - Фильтр «Только активные подписки» и живой поиск по названию куратора.
  - Кнопка инлайн-отписки **«❌ Отписаться»** прямо в таблице (вызывает нативный метод Steam `FollowCurator` с автоматической фиксацией даты отписки в локальной базе).
  - Прямые кликабельные ссылки на страницы профилей каждого куратора (`target="_blank"`).
- Все служебные настройки (экспорт базы в JSON, импорт базы из JSON, пересканирование) компактно вынесены в мини-кнопку шестеренку ⚙️ с выпадающим меню на странице куратора и на странице подписок.
- Обновлены автоматические тесты `test_tracker.js` для верификации режимов сортировки `oldest` и `newest`.

## [2.2.0] - 2026-10-19

### Added
- Функция импорта базы данных из файла JSON (`importCuratorsJSON`).
- Инициализация баз пользователей `basimova` и `⭐BK84` с простановкой исторических дат для 95 активных подписок.
- Дата создания базы зафиксирована на `2025-02-12T00:00:00.000Z`.

## [2.1.0] - 2026-10-19

### Added
- Автоопределение нового пользователя: баннер с кнопкой перехода к кураторам.
- Первичный обход кураторки на `/curators/mycurators` с единой стартовой датой создания БД.
- Приоритетная сортировка активных подписок перед отписанными.

## [2.0.0] - 2026-10-19

### Added
- Создан юзерскрипт `steam-curator-tracker.user.js` для страниц кураторов Steam (`/curator/*`).
- Учет дат подписки/отписки в реальном времени.

## [1.0.0] - 2026-10-19

### Added
- Переход на формат JSON, локальная база данных и компаратор двух баз кураторов.
