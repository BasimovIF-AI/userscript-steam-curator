# Steam Curator Follow Tracker (Userscript)

Кроссплатформенный (Chrome + Firefox под Tampermonkey / Violentmonkey) пользовательский скрипт для отслеживания подписок и отписок на кураторов в сообществе и магазине Steam.

---

## Возможности

1. **Неотличимый нативный дизайн Steam (Pixel-Perfect Steam UI — Новинка v2.7.1):**
   - Виджет органично встроен в строку элементов управления Steam рядом с кнопкой «В подписках» (`height: 34px`, `margin: 6px 0 0 10px`, `vertical-align: top`).
   - Идеальное совпадение нижней и верхней границ кнопок с нативной плашкой Steam `.follow_controls` пиксель-в-пиксель (`height: 34px`, внутренний `span` `height: 32px; line-height: 32px;`).
   - Использование официальных стилей и классов кнопок Steam (`btnv6_blue_hoverfade btn_medium`, `btnv6_white_transparent btn_medium`), оригинальной пиктограммы `ico_selected_green.png` и векторной SVG-шестеренки.
   - Полное отсутствие сторонних цветных эмодзи.
2. **Поддержка страниц разработчиков и издателей (Steam Creator Homes):**
   - Полная поддержка страниц создателей: `/developer/*`, `/publisher/*`, `/franchise/*` наряду с классическими `/curator/*`.
   - Автоматическое определение клана куратора (`clanId`), канонических URL и имен создателей.
3. **Лимит подписок Steam `(X/100)`:**
   - Счетчик на кнопке списка учитывает только реально активные подписки и мгновенно уменьшается при отписке.
4. **Автообновление даты подписки при переходе с функцией отмены (Undo):**
   - Автоматически актуализирует дату подписки при обычном заходе на куратора.
   - Кнопка **«Отменить»** позволяет вернуть предыдущую дату в один клик.
   - При переходе из внутренней таблицы ревизии дата **не перезаписывается** (защита через маркер ссылки `#sct_ref=list`).
   - Настройка отключается через шестеренку настроек.
5. **Портал настроек без обрезки (Fixed Portal):**
   - Меню настроек поверх всех слоев Steam (`z-index: 99999999`), не перекрывается нижними блоками сайта.
6. **Менеджер ревизии, отписок и повторных подписок:**
   - Кнопка **«Список (X/100)»** открывает интерактивное модальное окно.
   - **Сортировка по дате подписки:**
     - *Сначала старые (для отписки)* — мгновенно поднимает наверх самые ранние подписки для быстрой очистки лимита;
     - *Сначала новые* — хронологический порядок от свежих подписок к старым.
   - **Мгновенная инлайн-отписка в 1 клик (без popup-подтверждения):** вызов нативного метода Steam `FollowCurator` с мгновенным уменьшением счетчика активных кураторов `(X/100)`.
   - **Сохранение строки и обратная кнопка «Подписаться»:** после отписки куратор не исчезает из таблицы; на месте кнопки появляется статус «Отписан» и кнопка «Подписаться» для моментального возврата подписки.
   - Фильтр **«Только активные подписки»** и живой поиск по названию.
7. **Шестеренка настроек:**
   - `[✓] Автообновление даты при переходе` (включение/отключение);
   - `Экспорт базы (JSON)` — выгрузка отсортированного списка;
   - `Импорт базы (JSON)` — загрузка файла с историческими датами;
   - `Перейти к кураторам (/mycurators)`.
8. **Автоматический учет дат и статусов в реальном времени:**
   - Фиксирует действия подписки и отписки на страницах кураторов, разработчиков и издателей.
   - Отображает точный статус в шапке:
     - 🟢 *Подписан: [Дата]* (или с пометкой о создании БД);
     - 🔴 *Отписан: [Дата]*;
     - ⚪ *Новый куратор (ранее не отслеживался)*.
9. **Первичный обход кураторки для новых пользователей:**
   - Автоматический переход и сбор всех подписок на `/curators/mycurators` с единой стартовой датой создания БД.
10. **Кроссплатформенность и zero-overhead:**
    - Работает в Google Chrome, Mozilla Firefox, Brave, Microsoft Edge.
    - Чистый код без внешних библиотек (`@grant GM_setValue`, `GM_getValue`).

## Установка и запуск

1. Установите расширение менеджера скриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. Создайте новый скрипт и вставьте в него код [`steam-curator-tracker.user.js`](file:///e:/%D0%98%D0%BB%D1%8C%D0%B3%D0%B8%D0%B7/Documents/VibeCoding/TM_Scripts/userscript-steam-curator/steam-curator-tracker.user.js).
3. Перейдите на страницу любого куратора или страницу подписок:
   `https://store.steampowered.com/curators/mycurators/`
4. Нажмите **«📋 Список кураторов»** для ревизии и отписок, или **⚙️** для экспорта/импорта базы.
