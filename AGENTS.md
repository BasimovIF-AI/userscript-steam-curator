# AGENTS.md — Машинно-читаемый контекст проекта

## 1. Миссия, KPI и границы проекта (Mission & Scope)
- **Цель проекта:** Предоставить надежный, кроссплатформенный (Chrome + Firefox, Tampermonkey / Violentmonkey) инструмент для экспорта списка кураторов Steam в JSON, поддержания актуального локального снимка одного текущего пользователя и визуального сопоставления с базой другого пользователя.
- **KPI:**
  - 0 внешних CDN-зависимостей (`@grant GM_setValue`, `GM_getValue`, без утечек CSP).
  - $O(N)$ асимптотика алгоритма сравнения баз при объеме до 10 000 кураторов.
  - Мгновенная реакция интерфейса фильтрации (< 16 ms) на пользовательский ввод.
  - Точная нормализация идентификаторов кураторов по числовому Steam ClanID/slug.
- **Границы проекта (Non-Goals):**
  - Поддержка устаревших форматов экспорта (Excel/XLS исключены по требованию пользователя).
  - Хранение нескольких разных локальных профилей одновременно (сохраняется строго один активный профиль с перезаписью при обновлении).
  - Автоматическая массовая подписка/отписка от кураторов.

## 3. Архитектурные правила и инварианты
- **Engine First:** Логика парсинга DOM, нормализация ссылок и компаратор полностью отделены от слоя представления.
- **Идемпотентность и стабильность DOM:** Инжекция стилей и виджетов защищена проверкой идентификаторов (`steam-curators-sync-widget`, `steam-curators-sync-styles`). Периодический поллинг SPA-переходов (`setInterval` 1000ms) не создает дубликатов элементов.
- **Безопасность разметки:** Обязательное экранирование имен кураторов и пользовательских строк через `escapeHtml` перед вставкой в `innerHTML` для исключения XSS.
- **Хранилище:** Изолированное хранилище расширений (`GM_setValue`/`GM_getValue`) с fallback на `localStorage`.

## 4. Подводные камни и нетривиальные решения
- **Бесконечный скролл Steam:** Страница кураторов подгружается динамически. Алгоритм автоскролла отслеживает стабилизацию высоты (`scrollHeight`) с двойным контрольным подтверждением для предотвращения преждевременной остановки при медленном соединении.
- **Идентификация куратора:** Разные ссылки Steam могут содержать или не содержать имя куратора в URL (`/curator/12345/` vs `/curator/12345-Name/`). Функция `extractCuratorId` нормализует ключ до числового ID клана (`12345`), исключая ложные различия при переименовании.
